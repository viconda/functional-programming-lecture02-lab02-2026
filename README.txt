Функциональное программирование на Python. Работа 02

Репозиторий: https://github.com/viconda/functional-programming-lecture02-lab02-2026

lecture/ — 16 примеров, две практические таблицы и четыре задания СРС.
lab02/ — три примера, задания 1–6, вариант 3, тесты и эксперимент.
Все программы используют стандартную библиотеку Python 3.10+.

Запуск из корня репозитория:
python verify.py all
python -m unittest discover -s lab02 -v
python lab02/benchmark.py --show

В Windows можно запустить run_windows.cmd.
Полный эксперимент: python lab02/benchmark.py
Он перезапишет benchmark_results.json новыми измерениями.

Проверка оформления (Ruff устанавливается отдельно):
ruff check .
ruff format --check .

60 демонстраций и 38 тестов выполнены успешно.
Отчёты и снимки выполнения передаются отдельным архивом.

отчёты, изображения и личные сведения в неё не включены.
